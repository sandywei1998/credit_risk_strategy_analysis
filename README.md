
# 信贷风险分析与授信策略评估

## 一、项目背景

本项目基于 Python 生成的模拟信贷数据，模拟银行对公贷款业务中的风险识别与授信策略评估过程。通过 SQL、Python 和 Power BI，对企业经营特征、贷款表现及历史逾期情况进行分析，探索不同企业筛选规则对风险识别与审批金额保留比例的影响。

> **数据说明：** 本项目使用模拟数据，不涉及真实客户或金融机构业务数据。分析结果仅用于展示数据分析方法，不代表真实业务表现。

## 二、项目目标

- **数据处理：** 检查数据质量，整理企业、财务、贷款及贷款表现数据。
- **风险识别：** 基于历史逾期情况，分析不同企业筛选规则对风险贷款的识别效果。
- **策略评估：** 比较不同授信策略下的风险识别覆盖率、复核组逾期率及审批金额保留比例。
- **结果展示：** 使用 Power BI 构建分析看板，为授信策略比较提供数据支持。
- **敏感性分析：** 使用 Python 回测不同策略参数下的结果，观察策略表现的变化。

## 三、数据概况

项目通过 Python 生成模拟数据，主要包含以下数据表：

| 数据表 | 数据规模 | 主要内容 |
|---|---:|---|
| 企业信息 | 5,000 条 | 企业基本信息及经营年限等特征 |
| 财务信息 | 5,000 条 | 企业营业收入等财务指标 |
| 贷款信息 | 6,500 条 | 贷款记录及相关贷款信息 |
| 贷款表现 | 78,000 条 | 贷款历史表现及逾期信息 |

数据经过基础质量检查后，用于后续 SQL 分析、Python 回测及 Power BI 可视化。

## 四、分析方法

### 1. SQL：数据整理与授信策略评估

使用 SQL 完成多表关联、风险标签整理、筛选规则构建及策略效果统计。

项目设置了以下示例规则：

- **规则 A：** 筛选经营年限不足 3 年的企业。
- **规则 B：** 筛选年营业收入在 2,000 万至 5,000 万元之间的企业。
- **规则 C：** 满足规则 A 或规则 B 的企业。

通过比较基准组合与不同筛选策略，分析各策略覆盖的历史逾期贷款，以及对应的审批金额影响。

### 2. Python：历史回测与敏感性分析

使用 Python 对授信策略进行进一步评估，主要关注：

- 不同策略对历史逾期贷款的识别覆盖情况；
- 复核组的历史逾期率；
- 不同策略下的审批金额保留比例；
- 策略参数变化对评估结果的影响。

通过历史数据回测，观察策略之间的差异，为后续规则调整提供分析依据。

**注意：** 历史回测用于比较模拟数据中的策略表现，不代表策略在未来或真实业务中的实际效果。

### 3. Power BI：可视化分析

将 SQL 策略评估结果导入 Power BI，构建授信策略分析看板，集中展示关键指标和策略对比结果，便于观察不同筛选规则下的风险识别效果与审批金额影响。

## 五、关键评估指标

| 指标 | 说明 |
|---|---|
| 历史逾期贷款识别覆盖率 | 被策略识别的历史逾期贷款占全部历史逾期贷款的比例 |
| 复核组历史逾期率 | 被策略筛选进入复核范围的贷款中，历史逾期贷款所占比例 |
| 复核组审批金额 | 被策略筛选进入复核范围的贷款对应的审批金额 |
| 审批金额保留比例 | 假设拒绝复核组后，剩余审批金额占原审批金额的比例 |
| 策略敏感性 | 观察筛选条件变化对风险识别及审批金额指标的影响 |

上述指标用于从风险识别与业务规模两个角度比较策略，避免只关注风险指标而忽略审批金额的影响。

## 九、项目总结

本项目将 SQL 数据分析、Python 历史回测与 Power BI 可视化串联起来，形成从模拟数据准备、授信策略评估到分析结果展示的完整流程。

项目重点不在于预设某一条策略一定更优，而在于通过可复现的分析过程，比较风险识别能力与审批金额影响，并根据评估结果进一步讨论策略的适用性。
