\# 信贷风险分析与授信策略评估



\## 一、项目背景



本项目基于 Python 生成的模拟信贷数据，模拟银行对公贷款业务中的风险识别与授信策略评估过程。通过 SQL、Python 和 Power BI 对贷款表现进行分析，探索不同企业经营年限与营业收入筛选规则对历史逾期风险识别及审批金额保留比例的影响。



\*\*数据说明：\*\* 本项目使用模拟数据，不涉及真实客户或金融机构业务数据。分析结果仅用于展示数据分析方法，不代表真实业务表现。



\## 二、项目目标



\- 分析贷款组合的规模及历史逾期情况。

\- 使用 SQL 完成数据查询、风险指标计算与授信策略评估。

\- 对比不同授信筛选规则的风险识别效果。

\- 使用 Python 开展策略敏感性分析。

\- 使用 Power BI 展示风险指标及策略对比结果。



\## 三、使用工具



\- \*\*SQL / SQLite：\*\* 数据查询、关联分析、风险指标计算与策略评估。

\- \*\*Python：\*\* 数据处理、历史表现分析及策略敏感性分析。

\- \*\*Pandas：\*\* 数据整理与结果输出。

\- \*\*Power BI：\*\* 风险分析看板与策略可视化。



\## 四、分析内容



1\. 数据检查与贷款组合概况分析。

2\. 历史逾期情况及风险指标计算。

3\. 基于企业经营年限与营业收入的授信筛选规则设计。

4\. 不同策略的历史逾期识别覆盖率、复核组历史逾期率及审批金额保留比例对比。

5\. 通过 Python 调整策略阈值，观察策略结果的敏感性。

6\. 使用 Power BI 展示关键指标及策略比较结果。



\## 五、核心分析指标



\- \*\*历史逾期识别覆盖率：\*\* 被筛选策略识别出的历史逾期贷款数，占全部历史逾期贷款数的比例。

\- \*\*复核组历史逾期率：\*\* 被策略筛选进入复核组的贷款中，历史上发生逾期的贷款占比。

\- \*\*审批金额保留比例：\*\* 假设拒绝复核组贷款后，剩余审批金额占原审批金额的比例。



\## 六、分析结论



项目以企业经营年限不足 3 年或年营业收入处于 2,000 万至 5,000 万元的规则作为基准策略，并进一步调整经营年限和收入区间，比较不同阈值下的风险识别效果与审批金额保留情况。



分析表明，不同规则在历史逾期识别覆盖率和审批金额保留比例之间存在权衡：筛选范围扩大时，通常可以覆盖更多历史逾期贷款，但也可能影响更多原本可以保留的审批金额。



具体结论应结合项目生成的策略分析结果表及 Power BI 看板进行解读，不应仅凭单一指标认定某个策略最优。



\## 七、项目局限性



\- 数据为模拟数据，不能直接代表真实信贷业务。

\- 分析基于历史标签和规则筛选，不属于机器学习预测模型。

\- 历史关联不代表因果关系，策略的实际效果仍需结合真实业务数据、风险成本及业务约束进行验证。

\- 审批金额保留比例是规则情景下的估算指标，不等同于真实可实现的业务收益。



\## 八、项目结构



项目包含 SQL 分析脚本、Python 策略分析脚本、分析结果数据文件及 Power BI 可视化看板。各文件以实际仓库目录为准。
